# משחק הסימולציה: השוואת מנועים ומה נשמר מהאבטיפוס (28.10.2026)

סטטוס: **מסמך החלטה, ממתין לדוד.** לא הותקן דבר ולא נכתב קוד. המידע על רישוי וגרסאות נבדק בחיפוש ב-28.10.2026, וחלקו ממקורות צד שלישי. לפני התחייבות יש לאמת מול האתר הרשמי של כל כלי.

**מסקנה מרכזית:** בז'אנר הזה רמת הגרפיקה נקבעת בעיקר **באיור ובאנימציה**, ולא במנוע. כל ארבעת הכיוונים יכולים להציג דמויות מאוירות ברמה גבוהה. ההבדלים האמיתיים הם בעברית, בגודל ההורדה בדפדפן ובהתאמה לצוות.

## 3. ההמלצה
**ווב: TypeScript, PixiJS 8 או Phaser 4 לבמה (רקע, דמויות, אנימציה), ו-HTML/CSS לבועות, לבחירות ולתפריטים.** אופליין כ-PWA, אפליקציה בחנויות בהמשך דרך Capacitor, ואונליין דרך Supabase. הכלים חינמיים, ומשתמשים בתשתית הקיימת.

**PixiJS או Phaser:** ההחלטה תתקבל בניסוי הגרפי (שלב 3 למטה). PixiJS הוא מנוע תצוגה בלבד ומתאים למשחק שרובו דיאלוג ב-HTML. Phaser הוא מסגרת משחק מלאה, עם סצנות, אנימציות, סאונד וטעינה. Phaser 4 יצא רק באפריל 2026 (4.0.0, ואחריו 4.1.0), ולכן הוא חדש יחסית.

**תוכנית ב': Godot 4.** עוברים אליו אם בניסוי הגרפי מתברר שהווב לא מחזיק את האנימציה בטלפון ביניים, או אם יוחלט שהמשחק הוא אפליקציה מקורית קודם כול. בזכות המבנה בסעיף 4, המעבר יחייב לכתוב מחדש רק את שכבת התצוגה.

**נדחו:** Unity, בגלל העברית, משקל הווב וההתאמה לעבודה מקוד. Cocos ו-Defold, בגלל העברית.

## 4. מבנה שמונע שכתוב
ארבע שכבות נפרדות, מהיום הראשון של האבטיפוס:
1. **תוכן:** התסריט כנתונים (סצנות, בחירות, תנאים, סיומים). בלי קוד ובלי תלות במנוע.
2. **לוגיקת משחק:** מצב, מדדים, דגלים, תנאים וחישוב סיום. פונקציות טהורות בלי תצוגה, עם בדיקות.
3. **תצוגה:** מה שהשחקן רואה. השכבה היחידה שמשתנה בין האבטיפוס למשחק המלא, או בין ווב ל-Godot.
4. **שמירה:** ממשק אחד. עכשיו במכשיר בלבד, ובהמשך Supabase, בלי לגעת בשכבות האחרות. פורמט השמירה כולל מספר גרסה.

|---|---|---|
| התסריט, הדמויות והקול | **כן** | אחרי עריכה ותיקונים מהבדיקות |
| מבנה הנתונים של סצנות ובחירות | **כן** | השכבה הראשונה בסעיף 4 |
| לוגיקת המשחק (מדדים, דגלים, תנאים, סיומים) | **כן** | ייכתב כמודול JS נפרד בלי תצוגה, ויעבור ל-TypeScript. אם ייבחר Godot, יתורגם, והוא קטן |
| בדיקות הלוגיקה (כל סיום ניתן להשגה, אין מבוי סתום) | **כן** | |
| המספרים והאיזון | **כן, כנקודת פתיחה** | יכויל לפי הבדיקות |
| ממצאי הבדיקות עם אנשים | **כן** | הנכס הכי חשוב של האבטיפוס |
| הטיפים ותוכן המחברת | **כן** | מבוססים על הערכות הקיימות |
| דמויות SVG וגרפיקה | **לא, ניסוי בלבד** | **לא מייצגות את רמת הגרפיקה העתידית**, ויסומנו כך באבטיפוס עצמו |
| פריסת המסך, CSS ואנימציות | **לא** | ייבנו מחדש בשכבת התצוגה |
| שמירה במכשיר בלבד | **לא** | יוחלף בשכבת שמירה עם סנכרון |
| קובץ בלי כלי בנייה | **לא** | המשחק המלא ייבנה עם Vite ו-TypeScript, כנראה בריפו נפרד |

**מיקום האבטיפוס:** תיקייה `game-prototype/` בענף. הפריסה ל-Pages מעתיקה רק קבצי `*.html` משורש הריפו, ולכן תיקייה פנימית לא תתפרסם גם אם תמוזג בטעות. **זה משנה את מה שכתוב בתוכנית הקודמת**, שבה ההצעה הייתה `play.html` בשורש.
